影像尺寸篩選器 Image Dimension Filter

English

生效日期：2026 年 9 月 26 日

1. 資料收集

「影像尺寸篩選器 Image Dimension Filter」不會收集、接收或傳送任何個人身分識別資訊、使用數據或分析資料給開發者。本軟體沒有帳號系統、沒有廣告，也不做任何追蹤。

2. 本機處理

所有圖片處理、解析度篩選與檔案管理功能，完全在您的電腦上執行。本軟體不會將任何圖片、檔案路徑或元資料（Metadata）上傳給開發者、雲端服務或任何第三方。

3. 存放在您電腦上的資料

為了正常運作，本軟體只會在您自己的電腦上（使用者資料夾與 Windows 登錄檔）存放：您的設定（例如篩選條件與語言）、鎖定檔案清單、錯誤紀錄（技術性錯誤訊息，可能包含檔案路徑），以及試用使用紀錄（計數與已計入圖片的識別碼，不含圖片本身）。除非您主動提供（例如為了取得協助而將錯誤紀錄寄給我們），這些資料不會離開您的電腦。解除安裝本軟體時，這些資料不會自動刪除；如需協助移除，請與我們聯繫。

4. Microsoft Store

本軟體透過 Windows 內建的 Microsoft Store 服務查詢您是否已購買完整版，以及處理購買流程。這部分由 Microsoft 依 Microsoft 隱私權聲明 處理，開發者不會取得您的付款資訊或帳戶資料。

5. 政策修訂

本政策如有修訂，將公布於本頁並標示新的生效日期。
