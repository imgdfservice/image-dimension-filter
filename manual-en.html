2. Basic workflow

  1. Select a folder in the folder pane on the left. Before processing you are in “browse mode”: you can copy / cut / paste / delete / rename / create folders / drag / view. You can also select several folders at once with Ctrl / Shift in the folder pane, or by checking several subfolders in the thumbnail area.
  2. Set the orientation and filter in the main toolbar (see sections 3 and 4), and check “Include Subfolders” if needed.
  3. Click “Start Processing”. The app reads each image's resolution and marks low-resolution images (red text). If you selected several folders, all of them are processed in turn — not just the first one.
  4. In the thumbnail area, select the images you want to clean up (you can use the right-click menu and drag-and-drop), then delete them (they go to the Recycle Bin by default — see section 10).

3. Orientation (required) and filter modes

Orientation is a required setting for every “Start Processing”. It is to the left of “Filter Mode” and has three options:

  • Landscape: only images where width > height are checked; portrait and square images are skipped.
  • Portrait: only images where height > width are checked; landscape and square images are skipped.
  • Any: all images are checked regardless of orientation, including square images. To filter square images you must choose “Any” — a square image has equal width and height, so it never matches “Landscape” or “Portrait” and is skipped as a mismatch.

The order is: orientation first. Only images that match the orientation are then checked for low resolution using one of the three filter modes below; images that don't match are treated as not processed (never marked as low-resolution).

Choose one filter mode:

  • Size Settings: an image is low-resolution if its horizontal pixels (width) are under the set value or its vertical pixels (height) are under the set value.
    With “Portrait”, the vertical value you enter must be greater than the horizontal value; with “Landscape”, the horizontal value must be greater than the vertical value; both values must be greater than 0. If these rules aren't met, clicking “Start Processing” shows “Setting conflict — please adjust”. There is no such restriction with “Any”.
  • Either side under N: an image is low-resolution if either its width or its height is under N (the smaller of the two is checked).
  • By Format: pick a common format from the drop-down list (720p / 1080p / 1440p / 2160p / Higher). See section 4 for details.

“Set as Default” saves the current orientation, filter mode (including the format chosen for “By Format”) and values. They are applied immediately and automatically the next time you open the app.

4. By Format reference table

“By Format” always compares the image's short side (the smaller of width and height) using ranges: the short side must fall within the option's range (lower bound included, upper bound excluded). The ranges don't overlap:

OptionShort-side range (px)Rule
720p720 ≤ short side < 1080Within range → low-resolution
1080p1080 ≤ short side < 1440Within range → low-resolution
1440p1440 ≤ short side < 2160Within range → low-resolution
2160p2160 ≤ short side < 3840Within range → low-resolution
Highershort side ≥ 3840Within range → low-resolution (3840 is the 4K short side)

Example: with “1080p”, a 1600×1000 image has a short side of 1000, which is not in [1080, 1440), so it is not marked. With “720p”, the same image falls in [720, 1080) and is marked as low-resolution.

5. Include Subfolders

With “Include Subfolders” checked, “Start Processing” walks through every level below the selected folder. Each folder keeps its own results and shows its own red count in the folder pane.

  • The top folder's thumbnail area shows only the images at its own level; subfolders still appear as folder tiles — open them to see their results (results are not flattened into one view).
  • The Recycle Bin and system folders are skipped automatically; folders you don't have permission to read are skipped without stopping the whole run.
  • This checkbox is not remembered; it is unchecked each time the app opens (only the selected folder itself is scanned).

⚠️ Note: in the folder pane, a folder name shown in red only reflects whether that folder itself contains matching low-resolution images; it does not add up the results of its subfolders. If a folder has no matching images but one of its subfolders does, the folder still appears in black while collapsed — expand it with “+” to see the red subfolder. After processing multiple levels, it's a good habit to expand the tree and check, so you don't conclude that a folder has no low-resolution images underneath it.

6. Selecting, dragging, box selection

Mouse

  • Click: select only this item
  • Ctrl + click: toggle selection (click a selected item again to deselect it)
  • Shift + click: select a range
  • Click an empty area: clear the selection
  • Box selection: drag a box from an empty area; on release, the items inside are added to the selection
  • Double-click an image: open the Image Viewer; double-click a folder: open that folder

Drag to move

  • Drag images / folders onto another folder in the folder pane to move them there
  • Hover over a destination for about 0.7 seconds to expand it automatically
  • The folder pane scrolls automatically near its top and bottom edges
  • Dropping onto the same folder, or a folder into its own subfolder, is not accepted

Naming rule when pasting / moving onto an existing name

When you copy, cut and paste, or drag items into a folder that already has an item with the same name (including pasting back into the same folder), the app never overwrites the existing item. Instead it adds a number to the new item:

CaseOriginal nameNew name
File1.jpg1 (2).jpg → paste again: 1 (3).jpg
File that already has a number1 (2).jpg1 (3).jpg (the existing number is increased, skipping numbers already in use; never 1 (2) (2).jpg)
File with multiple extensionsa.tar.gza.tar (2).gz (only the part after the last “.” is treated as the extension)
File starting with a dot.gitignore.gitignore (2)
FolderPhotos.2024Photos.2024 (2) (folders have no extension; dots in the name are not treated as one)

The number is always inserted before the extension, so the new file still opens normally.

7. Right-click menus

There are three menus, depending on where you right-click:

  • On selected items: Open (images) / Copy / Cut / Lock / Unlock / Delete
  • On an empty area: New Folder / Paste / Sort (Name, Date, File Size, Dimensions × Ascending / Descending)
  • When a single folder is selected: the full folder menu (New / Copy / Cut / Paste / Rename / Delete Entire Folder / Properties)

8. Previous / Next

“◀ Previous” and “Next ▶” at the top left of the main toolbar, or the shortcuts Alt+← / Alt+→, move between folders you have visited (like a browser's back / forward).

9. Locking files

  • Locked files are not filtered (not marked red, not counted as low-resolution) and cannot be deleted.
  • Only files can be locked, not folders; if the selection includes folders, Lock / Unlock skips them.
  • Locked files can still be copied, cut and moved; only filtering and deleting are blocked.
  • How: the “🔒 Lock”, “🔓 Unlock” and “Unlock All” buttons in the thumbnail toolbar, or “Lock” / “Unlock” in the thumbnail right-click menu.
  • Locked thumbnails show a small 🔒 badge in the top-right corner; the Image Viewer title bar also shows 🔒 before the file name.
  • When batch-deleting a selection that includes locked files, the other items are deleted and the result window tells you how many were skipped.
  • When deleting a whole folder, if the folder (or any subfolder) contains a locked file, the deletion is refused with a message and nothing is deleted.
  • The lock list is saved and kept after you close and reopen the app; when files are moved or folders renamed inside the app, the lock records follow the new paths automatically.

10. Deleting and the Recycle Bin

Deleted items are moved to the Windows Recycle Bin by default, so you can restore anything deleted by mistake.

If the drive or location (for example removable media or a network drive) doesn't support the Recycle Bin, the app asks twice:
  1. “… doesn't support the Recycle Bin and will be permanently deleted. Continue?” (OK / Cancel)
  2. After OK: “Permanently delete these items? This cannot be undone.” (OK / Cancel)
Items are permanently deleted only if you choose OK both times; choosing Cancel at either step skips them.

When batch-deleting many files / folders, these two confirmations are asked only once for all the items that don't support the Recycle Bin, not once per file.

11. Stop Processing / Clear Results

  • While processing, “Start Processing” changes to “Stop Processing”; only one processing job runs at a time.
  • “Stop Processing” discards the results of that run; the folder stays “not processed” and you can process it again later.
  • “Clear Results” clears all processing results the app currently remembers (all red counts disappear and “Result Stats” is greyed out), and the thumbnail area returns to browse mode. It does not affect the lock list and needs no confirmation.
  • While processing you can still browse other folders, but “Rescan” and “Clear Results” are available only after the run finishes (or after you stop it).

12. Result Stats

“Result Stats” in the main toolbar becomes available after at least one successful “Start Processing”; it is greyed out when there are no results (including after “Clear Results”).

The statistics cover all processing results the app currently remembers (including every subfolder from recursive runs; they keep accumulating until you click “Clear Results”, not just the folder you are viewing):

  • Total images scanned: the number of images in all results.
  • Resolution buckets: by the image's long side (the larger of width and height) in four buckets: < 1920, 1921 ~ 2560, 2561 ~ 3840, > 3840 (the four buckets add up to the total scanned).
  • Matches cleanup criteria: count and total size, consistent with the red marking — locked files are not included.
  • Processing time: total time spent processing, accumulated until you click “Clear Results”.

The long-side buckets here and the short-side ranges of “By Format” (section 4) are two different definitions: “By Format” is a filter criterion (short side), while these buckets are only for statistics (always long side).

13. Image Viewer

Mouse

  • Left click: next image; left drag: pan
  • Right click: previous image
  • Multi-click left: zoom in; multi-click right: zoom out
  • Mouse wheel: zoom

Keyboard

  • ← / → / PgUp / PgDn: previous / next image (not affected by multi-click zoom)
  • + / = / −: zoom; 0: fit window
  • Delete: delete the current image (locked images show “This image is locked. Please unlock it first.”)
  • Esc: exit fullscreen → restore window → close, in that order

⚠️ Incomplete file warning

If an image file is truncated (for example an interrupted download or copy), the app displays whatever part was received instead of showing an error. The Image Viewer's info panel shows “⚠️ File incomplete, some content may be missing” to remind you that part of the picture (usually the bottom) may be missing. Thumbnails are displayed the same way.

14. Trial and full version

This software is a free download from the Microsoft Store and lets you filter 300 images for free. After that you can buy the “Full Version” inside the app to remove the limit (a one-time purchase, not a subscription). The trial and the full version are the same app — no reinstall is needed after purchase.

How the 300 images are counted

  • The count is the cumulative number of images that were filtered out (matched your criteria and marked red), not the number scanned. It accumulates across app sessions, however many folders you process at once.
  • Each image counts only once, identified by “file path + modified time”. Reprocessing or rescanning the same folder does not count already-counted images again.
  • An image that is moved, renamed or modified is treated as a new image and will be counted again when processed.
  • Locked images are not counted (they are not filtered). If you later unlock one and it turns red, it is counted at that moment.

Stopping at exactly 300

  • Example: 20 trial images remain and a run finds 50 matching images. Only the first 20 in scan order are marked red; the other 30 are not marked (but are still counted in the totals). When the run finishes, a message says the trial limit of 300 images has been reached and 30 more matching images were found but not marked; the message has “Buy Full Version” and “Close” buttons.
  • When several folders are processed as a batch, the message appears once, after the whole batch.
  • The status bar shows “(Trial remaining: N / 300)” after the processing result; this is not shown in the full version.

When the trial is used up

  • Only “Start Processing” is blocked: clicking it shows a message (with a “Buy Full Version” button).
  • Browsing, file operations (copy / cut / paste / delete), the Image Viewer, existing red results and Result Stats keep working.
  • When you change files in an already-processed folder, the app refreshes the results automatically: already-counted images stay red, and newly matching images are not marked.
  • The trial count is stored on this computer; uninstalling and reinstalling does not reset it.

How to buy the full version

  • Where: ① the “Help → Buy Full Version…” menu ② the “Buy Full Version” button in the trial-limit message.
  • Remaining images: shown in the status bar after processing, and in “Help → About” as “Trial version (N remaining)” or “Full version”.
  • Payment is completed in the Microsoft Store purchase window (this software never handles any payment information).
  • The purchase takes effect immediately, without restarting: you'll see “Thank you for your purchase! The full version is now activated.” and the menu changes to “✔ Full Version Activated”. Images left unmarked because of the trial limit are not reprocessed automatically — click “Start Processing” again.
  • Only the version installed from the Microsoft Store can make in-app purchases.

Purchase verification

  • Each time the app opens, it checks with the Microsoft Store whether you have purchased (an internet connection is needed). If you click “Start Processing” during the check, processing starts automatically once the check completes.
  • If the check can't be completed (for example no internet or a Store service problem), the app runs as the trial for this session (the trial count still applies) and shows “Unable to verify your purchase status right now. Please check your network connection and restart the app.” It checks again the next time it starts.

The trial count is signature-protected and stored in several places on your computer (your user folder and the Windows registry). If the records have been tampered with and can't be verified, the trial is treated as used up.

18. FAQ

What does “⚠️ File incomplete” in the Image Viewer mean?

The file was truncated while being saved or transferred (part of the end is missing). The app displays the part it received, but part of the picture (usually the bottom) may be missing. Other files are not affected.

A thumbnail shows “Cannot Preview”?

The file can't be decoded (it may be badly damaged, or not really an image). This is different from a truncated file and doesn't affect other files.

Can I recover deleted files?

Usually yes — restore them from the Windows Recycle Bin. Only items on locations that don't support the Recycle Bin (section 10), for which you chose OK in both confirmations, are permanently deleted.

My antivirus flags the app?

This software is distributed only through the Microsoft Store and is signed by Microsoft, so it is normally not flagged by antivirus software and shows no SmartScreen warning. Please don't use installers from unknown sources.

How do I report a problem?

Email imgdf.service@gmail.com with the steps you took and the messages you saw. If possible, attach %USERPROFILE%\.image_filter_gui\error.log (it contains technical error messages that may include file paths — you can review it before sending).

Is HEIC supported?

Not at the moment. Common formats that Pillow can read directly (such as JPG / PNG / BMP / GIF / TIFF) are supported.

After reaching the 300-image trial limit, can I still delete or browse images already found?

Yes. The limit only blocks “Start Processing” itself; existing results are unaffected and you can still browse, lock, delete and view Result Stats.

Do I need to buy again after changing computers or reinstalling?

No. Your purchase is tied to your Microsoft account. Sign in to the Microsoft Store with the same account and install the app; it is recognized as the full version when it opens.

I've purchased, but the app still shows the trial?

Check your internet connection and that the Microsoft Store is signed in with the account you purchased with, then restart the app.

How do I switch the interface language?

Use the “語言 Language” menu. The choice is saved and takes effect after you restart the app. By default the app uses Traditional Chinese if Windows is set to Traditional Chinese, and English otherwise.
