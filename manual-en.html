PART 1 · GETTING STARTED

1. Quick start

Follow these 5 steps to find low-resolution images and clean them up:

  1. Pick a folder: click the folder you want to check in the folder tree on the left (just like File Explorer; click “+” to expand subfolders).
  2. Choose an orientation: under “Orientation” at the top, choose Landscape / Portrait / Any. If unsure, choose “Any”.
  3. Set the filter: choose a filter mode and enter a value, for example “Either side under 1080”.
  4. Click “Start Processing”: matching low-resolution images are shown in red, and the thumbnail area shows only those images by default.
  5. Review and delete: select the images to remove and press Delete or right-click “Delete”. Files are moved to the Recycle Bin.

The interface language follows your Windows display language (Traditional Chinese systems show Traditional Chinese; all others show English). You can switch it from the “語言 Language” menu — see section 2.
You can filter 300 images for free, then buy the full version to remove the limit — see section 10.

PART 2 · FINDING LOW-RESOLUTION IMAGES

3. Choosing folders

  • One folder: click it in the folder tree.
  • Several folders: use Ctrl / Shift in the folder tree, or tick several subfolders in the thumbnail area. “Start Processing” processes all of them in turn, and the status bar shows the batch progress.
  • Include Subfolders: when ticked, every level of subfolders under the chosen folder is processed as well.
    • Each folder keeps its own results: the thumbnail area shows only the current level; open a subfolder to see its results. They are not merged into one page.
    • The Recycle Bin, system folders and folders you don't have permission to open are skipped automatically without stopping the run.
    • This checkbox is not remembered; it is unticked each time the app starts.

Before you click “Start Processing”, the app works like File Explorer: you can browse, copy, cut, paste, delete, rename and create folders.

4. Setting the filter

Step 1: Orientation (required)

The app checks orientation first. Only images with the matching orientation are then checked against the filter mode; the rest are skipped and never marked.

OptionImages that are checked
LandscapeWidth > height (portrait and square images are skipped)
PortraitHeight > width (landscape and square images are skipped)
AnyAll images, including square ones

To filter square images, choose “Any”. A square image has equal width and height, so it never matches “Landscape” or “Portrait”.

Step 2: Filter mode (choose one)

Filter modeAn image is low-resolution when…
Size SettingsHorizontal px (width) is below the value you set, or vertical px (height) is below the value you set
Either side under NWidth or height is below N (that is, the short side < N)
By FormatThe short side falls within the range of the chosen format (see the table below)

Value rules for “Size Settings”: both values must be greater than 0. With “Portrait”, vertical px must be greater than horizontal px; with “Landscape”, horizontal px must be greater than vertical px (no such rule with “Any”). Otherwise “Start Processing” shows “Setting conflict — please adjust”.

“By Format” reference table

Always compares the image's short side (the smaller of width and height). Each format is a range (lower bound included, upper bound excluded), and the ranges don't overlap:

OptionShort-side range (px)
720p720 ≤ short side < 1080
1080p1080 ≤ short side < 1440
1440p1440 ≤ short side < 2160
2160p2160 ≤ short side < 3840
Highershort side ≥ 3840

Example: a 1600×1000 image has a short side of 1000. With “1080p” it is not marked (1000 is not between 1080 and 1440); with “720p” it is marked (1000 is between 720 and 1080).

Set as Default

“Set as Default” saves the current orientation, filter mode (including the format chosen for “By Format”) and values. They apply immediately and are loaded automatically next time the app opens.

5. Processing and results

Start, stop, rescan, clear

  • Start Processing: reads each image's resolution and marks matching images in red; folder names in the folder tree also turn red and show a count.
  • Stop Processing: while running, “Start Processing” becomes “Stop Processing”. Stopping discards this run's results and the folder stays unprocessed; a multi-folder batch is cancelled as a whole.
  • Rescan: re-detects drives (for example after plugging in or removing a USB drive) and reloads the current folder; an already-processed folder is reprocessed with the current filter settings.
  • Clear Results: clears the results of all folders and returns to browsing. The lock list is not affected.
  • You can browse other folders while processing, but “Rescan” and “Clear Results” are available only after processing finishes (or after you stop it).
  • When you add, move or delete files in a processed folder, the app updates the results automatically.

The two display toggles in the thumbnail toolbar

Each button's label shows what it switches to when clicked:

  • “Show All Images” ⇄ “Low-Res Only”: available after processing; after processing, only low-resolution images are shown by default.
  • “Images Only” ⇄ “Show All”: “Images Only” hides subfolders and non-image files; “Show All” shows everything.

When the thumbnail area is empty, a message tells you which button to click to see the other items.

⚠️ A red folder name in the folder tree refers to that folder itself only; results from its subfolders are not added up. If a folder has no low-resolution images itself but a subfolder does, it stays black while collapsed — expand it with “+” to see the red subfolder. After processing several levels, expand the tree to check.

Result Stats

The “Result Stats” button becomes available after at least one run. It totals all current results (including subfolders) and keeps accumulating until you click “Clear Results”:

  • Total images scanned
  • Resolution buckets by long side: < 1920, 1921–2560, 2561–3840, > 3840 (for statistics only; “By Format” uses the short side, which is a different scheme)
  • Matches cleanup criteria: count and total size (locked files excluded, same as the red marks on screen)
  • Processing time: total time spent processing

Only one Result Stats window can be open at a time.

7. Locking files

Lock the images you want to keep so they can't be deleted by mistake.

  • How: “🔒 Lock”, “🔓 Unlock” and “Unlock All” in the thumbnail toolbar, or the thumbnail right-click menu. Locked thumbnails show 🔒 in the top-right corner, and the Image Viewer title shows 🔒 before the file name.
  • When locked: the file is never marked red, isn't counted as low-resolution and can't be deleted — but it can still be copied, cut and moved.
  • Only files can be locked, not folders (folders in the selection are skipped).
  • When batch-deleting, locked files are skipped, the rest are deleted, and you're told how many were skipped.
  • A folder that contains a locked file (in any subfolder) can't be deleted as a whole.
  • Locks are remembered after the app closes, and follow files you move or rename inside the app.

8. Deleting and the Recycle Bin

Deleted files are moved to the Windows Recycle Bin, so you can restore anything deleted by mistake.

If a file is on a location that doesn't support the Recycle Bin (such as some USB drives or network drives), you are asked twice:

  1. “… doesn't support the Recycle Bin and will be permanently deleted. Continue?”
  2. “Permanently delete these items? This cannot be undone.”

Items are permanently deleted only if you confirm both times; cancelling at either step keeps them. When batch-deleting, these two questions are asked only once for all such items.

PART 5 · TRIAL AND PURCHASE

10. Trial and full version

This app is a free download from the Microsoft Store and lets you filter 300 images for free. After that you can buy the “Full Version” inside the app to remove the limit (a one-time purchase, not a subscription). The trial and the full version are the same app — no reinstall is needed.

How the 300 images are counted

  • The count is the number of images marked red (matching your filter), not the number scanned; it accumulates across app sessions.
  • Each image counts only once (identified by “file path + modified time”), so reprocessing the same folder does not count it again.
  • An image that is moved, renamed or modified counts as a new image.
  • Locked images are not counted; if you later unlock one and it turns red, it is counted then.

Stopping at exactly 300

Example: 20 trial images remain and a run finds 50 matching images. Only the first 20 in scan order are marked; the other 30 are not. When the run finishes, a message says the trial limit of 300 images has been reached and 30 more matching images were found but not marked, with a “Buy Full Version” button. For a multi-folder batch, the message appears once, after the whole batch.

When the trial is used up

  • Only “Start Processing” is blocked. Browsing, file operations, the Image Viewer, existing red results and Result Stats keep working.
  • When you change files in a processed folder, already-counted images stay red and newly matching images are not marked.
  • The trial count is stored on this computer; uninstalling and reinstalling does not reset it. The records are signature-protected; if they have been tampered with and can't be verified, the trial is treated as used up.

Buying and checking your status

  • To buy: “Help → Buy Full Version…”, or the “Buy Full Version” button in the trial-limit message. Payment is completed in the Microsoft Store window; this app never handles any payment information.
  • It takes effect immediately, without restarting, and the menu changes to “✔ Full Version Activated”. Images left unmarked by the trial limit are not reprocessed automatically — click “Start Processing” again.
  • Remaining images: the status bar shows “(Trial remaining: N / 300)” after processing; “Help → About” shows “Trial version (N remaining)” or “Full version”.
  • Each time the app opens, it checks your purchase with the Microsoft Store (internet needed); if you click “Start Processing” during the check, processing starts once the check completes. If the check can't be completed, the app runs as the trial for this session and shows “Unable to verify your purchase status right now. Please check your network connection and restart the app.”
PART 6 · MORE

11. FAQ

Deleting and files

Q: Can I recover deleted files?
Yes — restore them from the Windows Recycle Bin. Files are deleted permanently only on locations that don't support the Recycle Bin, and only if you confirmed both times (see section 8).

Q: An image shows “⚠️ File incomplete”, or a thumbnail shows “Cannot Preview”?
“⚠️ File incomplete” means the file was cut off (for example an interrupted download or copy); the app shows as much as it can, and part of the picture may be missing. “Cannot Preview” means the file is badly damaged or isn't really an image. Neither affects other files.

Q: Is HEIC supported?
Not at the moment. Common formats such as JPG, PNG, BMP, GIF and TIFF are supported.

Trial and purchase

Q: After reaching the 300-image limit, can I still delete or browse images already found?
Yes. The limit only blocks “Start Processing”; you can still browse, lock and delete the results and view Result Stats.

Q: Do I need to buy again after changing computers or reinstalling?
No. Your purchase is tied to your Microsoft account. Sign in to the Microsoft Store with the same account and install the app; it is recognized as the full version when it opens.

Q: I've purchased, but the app still shows the trial?
Check your internet connection and that the Microsoft Store is signed in with the account you purchased with, then restart the app.

12. Troubleshooting and support

The app won't open, or nothing happens

If the app fails to start, it usually shows a “The app failed to start” message. If no message appears at all, please contact us as described below and attach the log files.

Reporting a problem

Email imgdf.service@gmail.com with the steps you took and the messages you saw. If possible, attach the log files from the %USERPROFILE%\.image_filter_gui\ folder:

FileContents
error.logUnexpected errors, and the reason if the app failed to start
startup.logThe most recent startup (if the app hangs, the last line shows where it stopped)
crash.logWhere the app was when it crashed (normally empty)

Tip: paste %USERPROFILE%\.image_filter_gui\ into the File Explorer address bar and press Enter to open this folder. Log files may contain file paths; feel free to check them before sending.
