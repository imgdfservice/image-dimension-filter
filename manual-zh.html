縮圖工具區的兩個顯示切換，與縮圖區空白時的提示

縮圖工具區有兩個切換按鈕，按鈕上的文字是「按下去會切換成什麼」：

  • 「顯示所有圖片」⇄「僅顯示低解析圖片」：只有按過「開始處理」後才能使用；處理完成後預設是「僅顯示低解析圖片」。
  • 「僅顯示圖片」⇄「完整顯示」：「僅顯示圖片」會隱藏子資料夾與非圖片檔案；「完整顯示」則全部顯示。

縮圖區沒有任何項目可顯示時，會依目前的狀態顯示不同的提示，告訴你要按哪個按鈕才看得到其他項目：

狀態縮圖區顯示的提示
尚未處理＋僅顯示圖片沒有圖片（目前是「僅顯示圖片」，按「完整顯示」可看全部項目）。
已處理＋僅顯示低解析圖片＋僅顯示圖片沒有圖片（目前是「僅顯示圖片」，按「完整顯示」，「顯示所有圖片」可看全部項目）。
已處理＋僅顯示低解析圖片＋完整顯示（且沒有子資料夾）沒有低解析度圖片（目前是「僅顯示低解析圖片」，按「顯示所有圖片」可看全部圖片）。
已處理＋顯示所有圖片＋僅顯示圖片沒有圖片（目前是「僅顯示圖片」，按「完整顯示」可看全部項目）。
資料夾本身沒有任何項目此資料夾是空的。

「尚未處理」時不會提到「顯示所有圖片」，因為那時這個按鈕還不能按。

2. 基本流程

  1. 左側檔案區選一個資料夾（未處理前是「純瀏覽模式」，可以複製 / 剪下 / 貼上 / 刪除 / 重新命名 / 新增資料夾 / 拖曳 / 檢視）；也可以在檔案區用 Ctrl / Shift 多選，或在縮圖區勾選多個子資料夾，一次選取多個資料夾。
  2. 在檔案工具區設定圖片方向與篩選條件（見第 3、4 節），需要的話勾選「包含子資料夾」。
  3. 按「開始處理」，讀出每張圖片的解析度並標記低解析度圖片（紅字）；若這次選取了多個資料夾，會依序全部處理完，不是只處理第一個。
  4. 在縮圖區選取要清理的圖片（可搭配右鍵選單、拖曳整理），確認後刪除（預設進資源回收桶，見第 10 節）。

3. 圖片方向（必要設定）與篩選方式

圖片方向是每次「開始處理」都一定要選的必要設定，在「篩選方式」左邊，選單有三個選項：

  • 橫向：只處理「寬 > 高」的圖片，直式圖與正方形圖片一律跳過、不判斷。
  • 縱向：只處理「高 > 寬」的圖片，橫式圖與正方形圖片一律跳過、不判斷。
  • 任意：不限方向，所有圖片都會判斷，含正方形圖片。若要篩選正方形圖片，請務必選「任意」——因為正方形寬高相等，選「橫向」或「縱向」都不會符合，會被當成方向不符而跳過。

處理順序是：先判斷圖片方向，符合方向的圖片才會進一步依下面三選一的篩選方式判斷是否為低解析度；不符合方向的圖片視同不處理（不會被標記為低解析度）。

篩選方式三選一：

  • 尺寸設定（v2.0.3 更名，原「寬 / 高各自門檻」）：水平像素（寬）小於設定值 或 垂直像素（高）小於設定值就算低解析度。
    選「縱向」時，輸入的「垂直像素」必須大於「水平像素」；選「橫向」時「水平像素」必須大於「垂直像素」；兩個數值都必須大於 0。 不符合規則時按「開始處理」會跳出「設定衝突，請重新調整」，請重新輸入。選「任意」時沒有這個限制。
  • 任一邊小於 N：只要圖片的寬或高任一邊小於 N（取寬高中較小者判斷）就算低解析度。
  • 依格式：從下拉選單選一個常見格式（720p / 1080p / 1440p / 2160p / 更高），詳細對照見第 4 節。

按「設為預設值」會把目前選到的圖片方向、篩選方式（含依格式選的格式）與數值存起來，下次開啟程式自動套用，也會立即套用到目前畫面。

4. 依格式對照表

「依格式」一律比對圖片的短邊（寬、高兩者中較小的那一個），v2.0.3 起改為區間制：短邊要落在該選項對應的區間內（下限含、上限不含）才算符合該格式，彼此區間不重疊：

下拉選單選項短邊區間（px）判斷邏輯
720p720 ≤ 短邊 < 1080短邊在此區間內 → 算低解析度
1080p1080 ≤ 短邊 < 1440短邊在此區間內 → 算低解析度
1440p1440 ≤ 短邊 < 2160短邊在此區間內 → 算低解析度
2160p2160 ≤ 短邊 < 3840短邊在此區間內 → 算低解析度
更高短邊 ≥ 3840短邊在此區間內 → 算低解析度（3840 為 4K 短邊）

例：選「1080p」時，一張 1600×1000 的圖片短邊是 1000，不在 [1080, 1440) 區間內，不會被標記；同一張圖若選「720p」，因為 1000 落在 [720, 1080) 區間內，會被標記為低解析度。這跟 v2.0.2「小於門檻」的定義不同，請以本表為準。

5. 包含子資料夾

勾選「包含子資料夾」後，「開始處理」會遞迴走訪選定資料夾底下所有層級，每一層資料夾各自保存結果、各自在檔案區顯示紅字數量。

  • 最上層資料夾的縮圖區只顯示它自己那一層的圖片，子資料夾仍以資料夾格子顯示，點進去看各自的結果（不會被攤平合併顯示）。
  • 會自動略過資源回收筒與系統保留資料夾；沒有存取權限的資料夾會直接跳過，不會中斷整個處理。
  • 此勾選狀態不會被記住，每次開啟程式預設不勾（維持原本只掃描單一資料夾的行為）。

⚠️ 提醒：檔案區左側樹狀圖裡，資料夾名稱是否顯示紅字，只反映「這個資料夾本身」目前是否有符合條件的低解析度圖片，不會往下累計子資料夾的結果。也就是說，如果某個資料夾本身沒有符合條件的圖片，但它的子資料夾裡有，這個資料夾在收合（未展開）狀態下仍會顯示黑字，必須點開左邊的「+」展開，才能看到子資料夾其實是紅字。建議處理多層資料夾後，養成把樹狀圖展開確認的習慣，避免誤判成「這個資料夾底下完全沒有低解析度圖片」。

6. 選取、拖曳、框選

滑鼠

  • 單擊：只選取這一項
  • Ctrl + 單擊：切換選取（已選取再點 = 取消選取）
  • Shift + 單擊：範圍選取
  • 點空白處：清除全部選取
  • 框選：在空白處拖曳出方框，放開後加選框內項目
  • 雙擊圖片：開啟圖片檢視器；雙擊資料夾：進入該資料夾

拖曳搬移

  • 拖曳圖片 / 資料夾到檔案區的其他資料夾可搬移過去
  • 拖到目的地上停留約 0.7 秒會自動展開該資料夾
  • 靠近檔案區上下緣會自動捲動
  • 同一個資料夾或「資料夾拖進自己底下」不會被接受

貼上 / 搬移遇到同名項目時的命名規則（v2.0.3.1 修正）

複製、剪下貼上，或拖曳搬移到已經有同名項目的資料夾（包含貼回原本所在的資料夾）時，程式不會覆蓋原檔，而是自動幫新項目加上序號：

情況原名稱新名稱
檔案1.jpg1 (2).jpg → 再貼一次 1 (3).jpg
檔案，名稱本身已帶序號1 (2).jpg1 (3).jpg（遞增現有序號，遇到已存在的序號會再往後跳，不會變成 1 (2) (2).jpg）
檔案，多重副檔名a.tar.gza.tar (2).gz（只把最後一個「.」之後當作副檔名）
開頭是點的檔案.gitignore.gitignore (2)
資料夾Photos.2024Photos.2024 (2)（資料夾沒有副檔名，名稱裡的點不會被當作副檔名）

序號一律插在副檔名前面，所以新檔案仍然可以正常開啟。v2.0.3 以前的舊版會把序號接在完整檔名後面（例如 1.jpg (2)），導致副檔名錯誤、無法開啟，v2.0.3.1 已修正。

7. 右鍵選單

依點擊位置分成三套：

  • 選取的項目上：開啟（圖片）/ 複製 / 剪下 / 鎖定 / 解鎖 / 刪除
  • 空白處：新增資料夾 / 貼上 / 排序（名稱、日期、檔案大小、尺寸 × 正序 / 倒序）
  • 只選了單一資料夾時：完整資料夾選單（新增 / 複製 / 剪下 / 貼上 / 重新命名 / 刪除完整資料夾 / 內容）

8. 上一頁 / 下一頁

檔案工具區左上角的「◀ 上一頁」「下一頁 ▶」，或快捷鍵 Alt+← / Alt+→，可在瀏覽過的資料夾之間切換（類似瀏覽器的上一頁 / 下一頁）。

9. 鎖定檔案

  • 鎖定的檔案不會被篩選（不標紅、不算進低解析度數量），也不能被刪除。
  • 只能鎖定檔案，不能鎖定資料夾；選取範圍含資料夾時，鎖定 / 解鎖動作會略過資料夾。
  • 鎖定的檔案仍可以複製、剪下、搬移，只有篩選與刪除會被擋下。
  • 操作方式：縮圖工具區的「🔒 鎖定」「🔓 解鎖」「一鍵解鎖」按鈕，或縮圖右鍵選單的「鎖定」「解鎖」。
  • 已鎖定的縮圖右上角會有一個 🔒 小徽章；圖片檢視器標題列的檔名前也會加上 🔒。
  • 批次刪除時若選取範圍包含鎖定的檔案，會刪除其餘可刪除的項目，並在結果視窗說明略過了幾個。
  • 刪除整個資料夾時，只要該資料夾（含子資料夾）內有任何鎖定的檔案，就會拒絕刪除並提示，不會整個刪掉。
  • 鎖定清單會存檔，關閉程式再打開也會保留；檔案在程式內被搬移或資料夾被改名時，鎖定記錄會自動跟著更新路徑。

10. 刪除與資源回收桶

從 v2.0.2 開始，刪除預設會移入 Windows 資源回收桶，誤刪可以從資源回收桶救回，不再是直接永久刪除。

若檔案所在的磁碟/位置（例如可攜式儲存媒體、網路硬碟）不支援資源回收桶，程式會依序跳出兩個確認視窗：
  1. 「所在的磁碟/位置不支援資源回收桶，將永久刪除，是否繼續？」（確認 / 取消）
  2. 選「確認」後，再跳一次「確認永久刪除，此動作無法復原」（確認 / 取消）
兩次都選「確認」才會真的永久刪除；任一次選「取消」，該項目就會被略過、不會刪除。

批次刪除（一次選很多檔案/資料夾）時，這兩個確認視窗只會針對「不支援資源回收桶的項目」合併問一次，不會每個檔案都各自跳窗。

11. 停止處理 / 清除處理結果

  • 「開始處理」在處理進行中會變成「停止處理」；同一時間只會跑一個處理工作。
  • 按下「停止處理」會丟棄這次的處理結果，該資料夾維持「未處理」狀態，可以之後再重新開始處理。
  • 「清除處理結果」會一次清掉目前程式記得的所有處理結果（所有資料夾標籤上的紅字數量都會消失，「結果統計」按鈕也會跟著反灰），縮圖區回到瀏覽模式；不會影響鎖定清單，也不需要額外確認。
  • 處理中仍可以在檔案區切換瀏覽其他資料夾，但「重新掃描」「清除處理結果」要等這次處理完成（或先按停止）才能使用。

12. 結果統計

在檔案工具區，「開始處理」成功跑完至少一次後才會亮起；沒有任何處理結果時是反灰的（按「清除處理結果」後也會變回反灰）。

點下去顯示的內容，統計範圍是目前程式記得的所有處理結果總和（含遞迴掃描時所有子資料夾的結果，「清除處理結果」之前會持續累計，不會只看你目前選取的這一個資料夾）：

  • 共掃描幾張圖片：所有已處理結果裡的圖片總數。
  • 解析度級距分布：依圖片長邊（寬、高中較大者）分成四級：< 1920、1921 ~ 2560、2561 ~ 3840、> 3840，各級距各自的張數（四個級距加總 = 共掃描張數）。
  • 符合清理條件：張數與總容量。這個數字跟畫面上紅字邏輯一致 —— 也就是已鎖定的檔案不會算進去。
  • 處理時間：累計花在處理上的時間，「清除處理結果」之前會持續累計。

解析度級距的長邊分級，跟第 4 節「依格式」的短邊分級是兩套不同的定義，請不要混用：依格式是篩選條件（三選一，比短邊），這裡的級距只是統計呈現用（固定比長邊）。

13. 圖片檢視器

滑鼠

  • 左鍵單擊：下一張；左鍵拖曳：平移圖片
  • 右鍵單擊：上一張
  • 連擊左鍵：放大；連擊右鍵：縮小
  • 滾輪：縮放

快捷鍵

  • ← / → / PgUp / PgDn：換頁（不受連擊放大 / 縮小影響）
  • + / = / −：縮放；0：符合視窗大小
  • Delete：刪除目前這張圖片（鎖定的圖片會提示「已鎖定，請先解鎖」）
  • Esc：依序 退出全螢幕 → 還原視窗 → 關閉

⚠️ 檔案不完整警告（v2.0.2 新增）

如果圖片檔案被截斷（例如下載到一半、複製中斷），程式會盡量用「已收到的部分」正常顯示，不會直接跳出錯誤擋住畫面；但圖片檢視器的資訊面板會顯示一行「⚠️ 檔案不完整，可能缺少部分內容」，提醒這張圖可能缺了一小塊畫面（通常是下半部）。縮圖區的縮圖也會用同樣的方式正常顯示，不會再出現「無法預覽」。

14. 試用版與完整版

本軟體在 Microsoft Store 免費下載，可以免費篩選 300 張圖片；之後可在程式內購買「完整版」解除限制（一次性購買，不是訂閱）。試用版與完整版是同一個程式，購買後不用重新安裝。

300 張怎麼算

  • 計算的是累計「被篩選出來（符合篩選條件、標成紅字）」的圖片張數，不是掃描總數；跨多次開啟程式累加，不論一次選幾個資料夾處理。
  • 同一張圖只算一次：以「檔案路徑＋修改時間」判斷。同一個資料夾重新處理、重新掃描，已經算過的圖不會重複扣。
  • 圖片被搬移、改名或修改內容後，會被當成新的一張，再處理時會再算一次。
  • 鎖定的圖片不計（本來就不會被篩選）。之後若解鎖、讓它變成紅字，才會在那時計入。

剛好 300 張就停

  • 例如試用只剩 20 張、這次掃出 50 張符合條件的圖：會依掃描順序只標示前 20 張紅字，其餘 30 張不標示（但仍會算出數量）。處理完會提示「已達試用上限 300 張，另有 30 張符合條件但未標示，購買完整版可解除限制」，提示視窗有「購買完整版」與「關閉」兩個按鈕。
  • 一次選多個資料夾批次處理時，整批跑完才提示一次。
  • 狀態列的處理完成訊息後面會顯示「（試用剩餘 N / 300 張）」；完整版不顯示。

額度用完之後

  • 只擋「開始處理」：按下去會跳出提示（含「購買完整版」按鈕）。
  • 瀏覽、複製/剪下/貼上/刪除等檔案操作、圖片檢視器、已經標示的紅字結果、結果統計都照常可用。
  • 對已處理過的資料夾做檔案操作時，程式會自動重新整理結果：已經算過的圖照樣標紅字，新出現的符合條件圖片不會標示。
  • 試用額度記錄在這台電腦上，解除安裝後重新安裝不會重置。

如何購買完整版

  • 購買入口：① 選單「說明 → 購買完整版…」 ② 試用上限提示視窗的「購買完整版」按鈕。
  • 查看剩餘張數：狀態列的處理完成訊息，以及「說明 → 關於」會顯示「試用版（剩餘 N 張）」或「完整版」。
  • 購買透過 Microsoft Store 的付款畫面完成（本軟體不經手任何付款資料）。
  • 購買後立即生效，不用重新啟動，會顯示「感謝購買！已啟用完整版」；選單會改成「✔ 已啟用完整版」。先前因試用上限而沒標示的圖片，請自行重新按「開始處理」（不會自動重跑）。
  • 只有從 Microsoft Store 安裝的版本才能在程式內購買。

購買狀態確認

  • 每次開啟程式時，會向 Microsoft Store 確認是否已購買（需要網路）。確認期間若按「開始處理」，會等確認完成後自動開始。
  • 若暫時無法確認（例如沒有網路、Store 服務異常），這次會先以試用版執行（試用額度照常計算），並提示「暫時無法確認購買狀態，請確認網路後重新啟動」；下次啟動會再確認一次。

試用計數有簽章保護、分存在電腦上多個位置（使用者資料夾與 Windows 登錄檔）。紀錄若被竄改而無法驗證，會視為試用額度已用完。

18. 常見問題

圖片檢視器顯示「⚠️ 檔案不完整」是什麼意思？

代表這個檔案在儲存/傳輸過程中被截斷了（缺了尾端一部分資料），程式已經盡量把收到的部分正常顯示出來，但畫面可能缺一小塊（通常是下半部）。不影響其他正常的檔案。

縮圖顯示「無法預覽」？

代表這個檔案無法被正常解碼（可能是嚴重損毀或根本不是圖片格式的假圖片檔），跟「檔案不完整」的截斷情況不同，不影響其他檔案。

刪除後可以救回來嗎？

一般情況下可以，直接到 Windows 資源回收桶還原即可。只有第 10 節提到的「不支援資源回收桶的位置」，且你在兩次確認視窗都選了「確認」，才會是真正的永久刪除。

防毒軟體對 exe 誤報？

本軟體只透過 Microsoft Store 發行，由 Microsoft 簽章，一般不會被防毒軟體誤報，也不會出現 SmartScreen 警告。請勿使用來源不明的安裝檔。

遇到問題要怎麼回報？

請來信 imgdf.service@gmail.com，說明操作步驟與看到的訊息；如果方便，請一併附上 %USERPROFILE%\.image_filter_gui\error.log（內容是技術性錯誤訊息，可能包含檔案路徑，寄出前可以自行檢查）。

支援 HEIC 格式嗎？

目前不支援 HEIC，僅支援 Pillow 能直接讀取的常見圖片格式（如 JPG / PNG / BMP / GIF / TIFF 等）。

試用版達到 300 張上限後，還能刪除或瀏覽已經找到的圖片嗎？

可以，上限只會擋下「開始處理」這個動作本身，已經找到的結果不受影響，仍然可以瀏覽、鎖定、刪除、查看結果統計。

換電腦或重新安裝後，要重新購買嗎？

不用。購買紀錄綁在你的 Microsoft 帳戶，用同一個帳戶登入 Microsoft Store 並安裝本軟體，開啟時就會自動確認為完整版。

已經購買，但程式還是顯示試用版？

請確認網路連線正常、Microsoft Store 已用購買時的帳戶登入，然後重新啟動程式。

怎麼切換介面語言？

使用選單「語言 Language」切換，選擇會被記住，重新啟動程式後生效。預設依 Windows 顯示語言：繁體中文系統顯示繁體中文，其他語言顯示英文。
