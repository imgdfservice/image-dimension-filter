一、開始使用

1. 快速上手

跟著下面 5 步，就能完成一次「找出低解析度圖片 → 清理」：

  1. 選資料夾：在左側檔案區點選要檢查的資料夾（跟檔案總管一樣，展開「+」可以看子資料夾）。
  2. 選圖片方向：在上方「圖片方向」選 橫向 / 縱向 / 任意。不確定就選「任意」。
  3. 設定篩選條件：選一種篩選方式並輸入數值，例如「任一邊小於 1080」。
  4. 按「開始處理」：符合條件的低解析度圖片會以紅字標示，縮圖區預設只顯示這些圖片。
  5. 檢查並刪除：選取要清理的圖片，按 Delete 或右鍵「刪除」，檔案會移到資源回收桶。

介面語言會依 Windows 顯示語言自動選擇（繁體中文系統顯示繁中，其他顯示英文），可從選單列「語言 Language」切換，見第 2 節。
本軟體可免費篩選 300 張圖片，之後可購買完整版解除限制，見第 10 節。

二、找出低解析度圖片

3. 選擇資料夾

  • 單一資料夾：在檔案區點一下。
  • 多個資料夾：在檔案區用 Ctrl / Shift 多選，或在縮圖區勾選多個子資料夾。按「開始處理」會依序全部處理，狀態列會顯示批次進度。
    檔案區的多選只用於批次處理；在檔案區拖曳時，一次只會搬移或複製滑鼠按住的那一個資料夾（見第 6 節）。
  • 包含子資料夾：勾選後，會處理選定資料夾底下所有層級的子資料夾。
    • 每個資料夾各自保存結果：縮圖區只顯示目前這一層的圖片，子資料夾要點進去看，不會合併成一整頁。
    • 資源回收筒、系統保留資料夾、沒有存取權限的資料夾會自動略過，不會中斷處理。
    • 這個勾選不會被記住，每次開啟程式預設不勾。

還沒按「開始處理」之前，程式就像檔案總管，可以瀏覽並複製、剪下、貼上、刪除、重新命名、新增資料夾。

4. 設定篩選條件

第一步：圖片方向（必要）

程式會先判斷圖片方向，方向符合的圖片才會再用篩選方式判斷；方向不符的圖片直接跳過，不會被標記。

選項會判斷的圖片
橫向寬 > 高（直式圖與正方形圖片跳過）
縱向高 > 寬（橫式圖與正方形圖片跳過）
任意所有圖片，包含正方形

要篩選正方形圖片，請選「任意」。正方形寬高相等，選「橫向」或「縱向」都不會符合。

第二步：篩選方式（三選一）

篩選方式判斷為低解析度的條件
尺寸設定水平像素（寬）小於設定值，或垂直像素（高）小於設定值
任一邊小於 N寬或高任一邊小於 N（也就是短邊 < N）
依格式短邊落在所選格式的區間內（見下表）

「尺寸設定」的數值規則：兩個數值都必須大於 0。選「縱向」時垂直像素必須大於水平像素，選「橫向」時水平像素必須大於垂直像素（選「任意」沒有這個限制）。不符合時按「開始處理」會提示「設定衝突，請重新調整」。

「依格式」對照表

一律比對圖片的短邊（寬、高中較小者）。每個格式是一段區間（含下限、不含上限），彼此不重疊：

選項短邊區間（px）
720p720 ≤ 短邊 < 1080
1080p1080 ≤ 短邊 < 1440
1440p1440 ≤ 短邊 < 2160
2160p2160 ≤ 短邊 < 3840
更高短邊 ≥ 3840

例：一張 1600×1000 的圖片，短邊是 1000。選「1080p」不會被標記（1000 不在 1080～1440 之間）；選「720p」會被標記（1000 在 720～1080 之間）。

設為預設值

按「設為預設值」會把目前的圖片方向、篩選方式（含「依格式」選的格式）與數值存起來，立即套用，下次開啟程式也會自動帶入。

5. 處理與查看結果

開始、停止、重新掃描、清除

  • 開始處理：讀出每張圖片的解析度，把符合條件的圖片標成紅字；檔案區的資料夾名稱也會顯示紅字與數量。
  • 停止處理：處理中「開始處理」會變成「停止處理」。停止後這次的結果會丟棄，資料夾維持未處理；多選的批次會整批取消。
  • 重新掃描：重新偵測磁碟機（例如插拔隨身碟後），並重新讀取目前的資料夾；已處理過的資料夾會用目前的篩選條件重新處理。
  • 清除處理結果：清掉所有資料夾的處理結果，回到瀏覽狀態。鎖定清單不受影響。
  • 處理中仍可以瀏覽其他資料夾，但「重新掃描」「清除處理結果」要等處理完成（或先停止）才能用。
  • 在已處理的資料夾裡新增、搬移、刪除檔案時，程式會自動更新結果。

縮圖工具區的兩個顯示切換

按鈕上的文字是「按下去會切換成什麼」：

  • 「顯示所有圖片」⇄「僅顯示低解析圖片」：處理後才能使用，處理完成預設只顯示低解析圖片。
  • 「僅顯示圖片」⇄「完整顯示」：「僅顯示圖片」會隱藏子資料夾與非圖片檔；「完整顯示」全部顯示。

縮圖區空白時，會提示你要按哪個按鈕才看得到其他項目。

⚠️ 檔案區的紅字只代表「這個資料夾本身」，不會把子資料夾的結果往上累計。一個資料夾本身沒有低解析度圖片、但子資料夾有時，收合狀態下它仍是黑字，展開「+」才看得到紅字的子資料夾。處理多層資料夾後，建議展開樹狀圖確認。

結果統計

處理過至少一次後，「結果統計」按鈕才能使用。統計的是目前所有處理結果的總和（含子資料夾），在「清除處理結果」之前會持續累計：

  • 共掃描幾張圖片
  • 解析度級距分布：依長邊分成 < 1920、1921～2560、2561～3840、> 3840 四級（只是統計用，跟「依格式」比短邊是不同的分法）
  • 符合清理條件：張數與總容量（不含鎖定的檔案，跟畫面上的紅字一致）
  • 處理時間：累計花在處理上的時間

統計視窗同一時間只能開一個。

三、整理檔案

6. 選取與檔案操作

在縮圖區選取

操作效果
單擊只選取這一項
Ctrl + 單擊加選 / 取消選取這一項
Shift + 單擊範圍選取
在空白處拖曳框選，放開後加選框內項目
點空白處清除全部選取
雙擊圖片 / 資料夾開啟圖片檢視器 / 進入資料夾

右鍵選單

  • 在選取的項目上：開啟（圖片）、複製、剪下、鎖定、解鎖、刪除。
  • 只選了單一資料夾時：新增、複製、剪下、貼上、重新命名、刪除完整資料夾、內容。
  • 在空白處：新增資料夾、貼上、排序（名稱 / 日期 / 檔案大小 / 尺寸，正序或倒序）。

拖曳搬移與複製

  • 在縮圖區選取圖片、檔案或資料夾後，拖到左側檔案區的資料夾，或縮圖區裡的資料夾縮圖上，就會搬移過去。可以放開的目標會以藍框標示；放在檔案縮圖或空白處不會有動作，資料夾也不能拖到自己身上。
  • 拖到縮圖區的上下邊緣時，縮圖區會自動捲動。
  • 在檔案區拖曳資料夾時，一次只會搬移或複製滑鼠按住的那一個資料夾（檔案區的多選只用於批次處理）。要一次搬移多個項目，請在縮圖區選取後拖曳。
  • 拖曳時按住 Ctrl 就會變成複製（跟檔案總管一樣），原本的檔案留在原處。以放開滑鼠那一刻有沒有按著 Ctrl 為準，拖到一半再按也可以；跟著滑鼠的提示會即時顯示「移動到」或「複製到」，放開後的確認視窗也會寫明是搬移還是複製。
  • 上面各種拖曳都可以用 Ctrl 複製。
  • 複製出來的檔案不會帶著鎖定（跟「複製 / 貼上」一樣）。複製的圖片路徑不同，被標成紅字時，試用額度會把它當成新的一張（見第 10 節）。
  • 在檔案區的資料夾上停留約 0.7 秒會自動展開；靠近檔案區上下緣會自動捲動。
  • 拖到原本所在的資料夾（按住 Ctrl 也一樣），或把資料夾拖進它自己底下，不會被接受。想在同一個資料夾裡複製一份，請用 Ctrl+C / Ctrl+V。

遇到同名項目

貼上、搬移或複製到已有同名項目的資料夾時，不會覆蓋原檔，而是自動加上序號（序號插在副檔名前面，檔案仍可正常開啟）：

情況原名稱新名稱
一般檔案1.jpg1 (2).jpg → 再貼一次 1 (3).jpg
名稱已帶序號1 (2).jpg1 (3).jpg（遞增序號，不會變成 1 (2) (2).jpg）
多重副檔名a.tar.gza.tar (2).gz（只把最後一個「.」之後當副檔名）
開頭是點的檔案.gitignore.gitignore (2)
資料夾Photos.2024Photos.2024 (2)（資料夾名稱裡的點不當副檔名）

上一頁 / 下一頁

檔案工具區左上角的「◀ 上一頁」「下一頁 ▶」（或 Alt+← / Alt+→），可以在瀏覽過的資料夾之間切換，跟瀏覽器一樣。

7. 鎖定檔案

想保留的圖片可以先鎖定，避免誤刪。

  • 怎麼鎖：縮圖工具區的「🔒 鎖定」「🔓 解鎖」「一鍵解鎖」，或縮圖右鍵選單。已鎖定的縮圖右上角有 🔒，圖片檢視器標題的檔名前也會有 🔒。
  • 鎖定後：不會被標成紅字、不算進低解析度數量、不能刪除；但仍可以複製、剪下、搬移。
  • 只能鎖定檔案，不能鎖定資料夾（選取範圍含資料夾時會略過資料夾）。
  • 批次刪除時，鎖定的檔案會被略過，其餘照常刪除，並告訴你略過了幾個。
  • 資料夾（含子資料夾）裡只要有鎖定的檔案，整個資料夾就不能刪除。
  • 鎖定會被記住，關閉程式再開也還在；在程式內搬移或改名時會自動跟著更新。

8. 刪除與資源回收桶

刪除的檔案會移到 Windows 資源回收桶，誤刪可以從資源回收桶還原。

如果檔案所在的位置不支援資源回收桶（例如部分隨身碟、網路磁碟），會依序跳出兩次確認：

  1. 「所在的磁碟/位置不支援資源回收桶，將永久刪除，是否繼續？」
  2. 「確認永久刪除，此動作無法復原」

兩次都選「確認」才會永久刪除；任一次選「取消」就不刪。批次刪除時，這兩次確認只會針對這類項目合併問一次。

四、圖片檢視器

五、試用與購買

10. 試用版與完整版

本軟體在 Microsoft Store 免費下載，可免費篩選 300 張圖片，之後可在程式內購買「完整版」解除限制（一次性購買，不是訂閱）。試用版與完整版是同一個程式，購買後不用重新安裝。

300 張怎麼算

  • 算的是被標成紅字（符合篩選條件）的圖片，不是掃描總數；跨多次開啟程式累加。
  • 同一張圖只算一次（以「檔案路徑＋修改時間」判斷），重新處理同一個資料夾不會重複扣。
  • 圖片被搬移、改名或修改內容後，會當成新的一張。
  • 鎖定的圖片不計；之後解鎖並變成紅字時才計入。

剛好 300 張就停

例如試用只剩 20 張，這次找到 50 張符合條件的圖：會依掃描順序只標示前 20 張，其餘 30 張不標示。處理完會提示「已達試用上限 300 張，另有 30 張符合條件但未標示，購買完整版可解除限制」，並提供「購買完整版」按鈕。多個資料夾批次處理時，整批跑完才提示一次。

額度用完之後

  • 只有「開始處理」會被擋下。瀏覽、檔案操作、圖片檢視器、已標示的紅字結果、結果統計都照常可用。
  • 在已處理的資料夾做檔案操作時，已經算過的圖照樣標紅字，新出現的符合條件圖片不會標示。
  • 試用額度記錄在這台電腦上，解除安裝再重新安裝不會重置。記錄有簽章保護，被竄改而無法驗證時會視為額度已用完。

購買與查看狀態

  • 購買：選單「說明 → 購買完整版…」，或試用上限提示視窗的「購買完整版」按鈕。付款在 Microsoft Store 的畫面完成，本軟體不經手任何付款資料。
  • 購買後立即生效，不用重新啟動，選單會變成「✔ 已啟用完整版」。先前因上限而未標示的圖片，請重新按「開始處理」。
  • 查看剩餘張數：狀態列的處理完成訊息會顯示「（試用剩餘 N / 300 張）」；「說明 → 關於」會顯示「試用版（剩餘 N 張）」或「完整版」。
  • 每次開啟程式會向 Microsoft Store 確認購買狀態（需要網路），確認期間按「開始處理」會等確認完再開始。暫時無法確認時，這次先以試用版執行，並提示「暫時無法確認購買狀態，請確認網路後重新啟動」。

11. 常見問題

刪除與檔案

Q：刪除後可以救回來嗎？
可以，到 Windows 資源回收桶還原即可。只有在不支援資源回收桶的位置、而且兩次確認都選「確認」時，才是永久刪除（見第 8 節）。

Q：圖片出現「⚠️ 檔案不完整」，或縮圖顯示「無法預覽」？
「⚠️ 檔案不完整」代表檔案被截斷（例如下載或複製中斷），程式會盡量顯示已有的部分，畫面可能缺一塊。「無法預覽」代表檔案嚴重損毀或不是真正的圖片。兩者都不影響其他檔案。

Q：支援 HEIC 格式嗎？
目前不支援。支援 JPG、PNG、BMP、GIF、TIFF 等常見格式。

試用與購買

Q：達到 300 張上限後，還能刪除或瀏覽已經找到的圖片嗎？
可以，上限只擋「開始處理」，已找到的結果仍可瀏覽、鎖定、刪除、查看結果統計。

Q：換電腦或重新安裝後，要重新購買嗎？
不用。購買紀錄綁在你的 Microsoft 帳戶，用同一個帳戶登入 Microsoft Store 安裝本軟體，開啟時就會自動確認為完整版。

Q：已經購買，但程式還是顯示試用版？
請確認網路正常、Microsoft Store 已用購買時的帳戶登入，然後重新啟動程式。

12. 疑難排解與回報

程式打不開，或點了沒反應

啟動失敗時通常會跳出「程式啟動失敗」訊息視窗。如果連訊息視窗都沒出現，請依下方方式回報，並附上記錄檔。

回報問題

請來信 imgdf.service@gmail.com，說明操作步驟與看到的訊息。方便的話，請附上 %USERPROFILE%\.image_filter_gui\ 資料夾裡的記錄檔：

檔案內容
error.log未預期的錯誤，以及啟動失敗的原因
startup.log最近一次啟動的過程（程式卡住時，最後一行是停住的步驟）
crash.log程式閃退時的位置（平常是空的）

小技巧：把 %USERPROFILE%\.image_filter_gui\ 貼到檔案總管的網址列，按 Enter 就能打開這個資料夾。記錄檔可能包含檔案路徑，寄出前可以自行檢查。
